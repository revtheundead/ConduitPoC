# conduit Library Documentation

[Back to top-level documentation](../index.md)

conduit is the C++20 runtime library that powers protocol communication. It provides error handling, bit-level I/O, network transports, stream framing, and the `Transceiver` orchestrator that connects generated protocol sessions to real-world I/O -- letting you send and receive typed messages without touching raw bytes.

## Terminology

| Term | Meaning |
|------|---------|
| **Frame** | The outermost wire-level structure. In v2, defined by `<frame>`; in v1, the entry-point message. Contains header fields, a payload, and optional footer fields. |
| **Message** | A user-facing protocol entity. In v2, declared with `<message id="...">` and dispatched by the frame's ID field. In v1, any `<message>` with `role="entry-point"`. |
| **Struct** | A reusable data container (`<struct>`). Structs compose to build messages and frames. |
| **Leaf Type** | A concrete type reachable from an entry-point or frame that users send/receive. Each leaf has a `TYPE_ID` and `TYPE_NAME`. |
| **Session** | A stateful encoder/decoder implementing `ISession`. Maps between wire bytes and typed messages. Generated by bgen. |
| **Peer** | A named communication endpoint in the Transceiver, with its own session instance and transport. |

## Layer Architecture

```
┌─────────────────────────────────────────────┐
│              Transceiver                    │  Orchestrates peers, handlers, dispatch
├──────────┬──────────┬───────────────────────┤
│ Handlers │  Queue   │     StreamFramer      │  Message dispatch, back-pressure, framing
├──────────┴──────────┴───────────────────────┤
│              Transports                     │  TCP client/server, UDP, Serial
├─────────────────────────────────────────────┤
│          Sessions / Codec Traits            │  ISession, Encodable, Decodable, Message
├──────────────────┬──────────────────────────┤
│    BitReader     │     BitWriter            │  Bit/byte-level encode/decode
├──────────────────┴──────────────────────────┤
│            Core (Error, Types)              │  ErrorCode, Result<T>, VoidResult
└─────────────────────────────────────────────┘
```

## Umbrella Header

```cpp
#include <conduit/conduit.hpp>
```

This pulls in all conduit headers except `<conduit/string/encoding.hpp>` (which is rarely needed directly -- generated code calls it automatically). For fine-grained control, include individual headers (e.g., `<conduit/core/error.hpp>`).
